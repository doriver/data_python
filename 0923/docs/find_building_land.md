# 건물 실거래가 데이터를 토지특성정보로 매핑

건물 실거래 데이터의 '시군구, 확정번지'를 통해 토지특성정보에서 건물이 위치한 토지를 찾는다. 해당토지의 'PNU, 토지면적, 공시지가' 를 건물 실거래 데이터에 추가한다.

* 실거래 데이터 경로 : data\raw
    * 해당 경로에 있는 xlsx파일 모두 처리
* 토지특성정보 : data\basis\서울_26_토지특성정보.csv
* data\processed 에 결과물은 만든다.
* 참고 스크립트 : land_data_engineer\find_land_nationwide.py
    * 전국 확장은 추후에 할 예정

* 통계치들은 아래 사항만 뽑는다
    * 처리대상 개수, 매칭 성공 건수, 매칭 성공률


## 매핑및 데이터 추가

* 건물 실거래 데이터에 '확정번지'가 없는경우는 처리하지 않는다

* 실거래 데이터의 '시군구' 컬럼값 = 토지특성정보의 '법정동명' 컬럼값
* 실거래 데이터의 '확정번지' 컬럼값 = 토지특성정보의 '지번' 컬럼값
    * 확정번지 값이 '산' 으로 시작할경우, 토지특성정보의 '대장구분명' 컬럼값이 '산' 이여야 한다.

* 해당토지의 고유번호, 토지면적, 공시지가를 실거래 데이터에 추가
