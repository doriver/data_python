# 일반건물 실거래 데이터를 건축물대장 데이터를 통한 매핑

일반건물 실거래 데이터의 번지는 마스킹 처리 돼있는데, 건축물대장에 매핑을 통해 해당 번지를 구해, 확정번지가 추가된 실거래 데이터를 만든다. 

* 실거래 데이터 경로 : data\raw
    * 해당 경로에 있는 xlsx파일 모두 처리
* 건축물대장 : data\basis\건축물대장_20260821163300_일반.csv
* data\processed 에 결과물은 만든다.
* 참고 스크립트 : find_house_buillding.py

* 통계치들은 아래 사항만 뽑는다
    * 전체 건수, 매칭 성공 건수, 매칭 성공률

## 매핑 방법

'고유 매핑키'로 필터링한 건축물대장 데이터가 1개일경우 확정, 후보가 2개 이상인 경우는 '서브 매핑키'로 필터링해  후보가 1개인경우 확정하고 그렇지 않은경우 매칭 실패

* 실거래 데이터에서 아래 케이스들은 제외(결과물 xlsx파일에서 삭제)한다 
    * '유형'컬럼 값이 '집합' 인경우
    * '지분구분'컬럼 값이 '지분' 인경우
    * '층'컬럽에 값이 있는경우

* 아래 컬럼들은 '실거래 데이터 컬럼(그에 대응하는 건축물대장 컬럼들)' 형식을 취한다.

* 고유 매핑키
    * 컬럼들 : 시군구(시도, 시군구, 법정동), 지번(번, 지), 연면적(연면적)
    * 마스킹된 번지 컬럼은 "본번의 자릿수 + 맨 앞자리 숫자"만을 나타낸다. *의 경우는 1자리이고 맨 앞숫자는 알수 없는것이다.

* 서브 매핑키
    * 컬럼들 : 건축년도(사용승인일), 건축물주용도(주용도), 용도지역(용도지역코드명정보), 대지면적(대지면적)
    * 적힌 컬럼 순서로 필터링, 앞 컬럼으로 필터링 했을때 후보가 1개로 되면 확정, 후보가 2개 이상이면 다음 컬럼으로 필터링
