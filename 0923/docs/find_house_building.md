# 단독/다가구 실거래 데이터를 건축물대장 데이터를 통한 매핑

단독/다가구 실거래 데이터의 번지는 마스킹 처리 돼있는데, 건축물대장에 매핑을 통해 해당 번지를 구해, 확정번지가 추가된 실거래 데이터를 만든다. 

* 단독/다가구 실거래 데이터 : data\raw\단독다가구(매매)_실거래가_20260910114706.xlsx
* 건축물대장 : data\basis\건축물대장_20260821163300.xlsx
* data\processed 에 결과물은 만든다.
* 참고 스크립트 : land_data_engineer\find_land_nationwide.py
    * 전국 확장은 추후에 할 예정
* 통계치들은 아래 사항만 뽑는다
    * 전체 건수, 매칭 성공 건수, 매칭 성공률

## 매핑 방법
'고유 매핑키'로 필터링한 건축물대장 데이터가 1개일경우 확정, 후보가 2개 이상인 경우는 '서브 매핑키'로 필터링해  후보가 1개인경우 확정하고 그렇지 않은경우 매칭 실패

* 건축물 대장에서 '대장구분'컬럼의 값이 '일반'인 경우만 기준데이터로 쓴다.(단독/다가구는 집합건물이 아닌 일반건물임)
* 아래 컬럼들은 '실거래 데이터 컬럼(그에 대응하는 건축물대장 컬럼들)' 형식을 취한다.

* 고유 매핑키
    * 컬럼들 : 시군구(시도, 시군구, 법정동), 번지(번, 지), 연면적(연면적), 건축년도(사용승인일)
    * 마스킹된 번지 컬럼은 "본번의 자릿수 + 맨 앞자리 숫자"만을 나타낸다. *의 경우는 1자리이고 맨 앞숫자는 알수 없는것이다.

* 서브 매핑키
    * 컬럼들 : 주택유형(주용도), 대지면적(대지면적)
    * 적힌 컬럼 순서로 필터링, 앞 컬럼으로 필터링 했을때 후보가 1개로 되면 확정, 후보가 2개 이상이면 다음 컬럼으로 필터링
