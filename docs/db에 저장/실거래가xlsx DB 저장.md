# 토지 실거래 데이터들을 db에 저장

data\processed\20250806_20260805_토지(매매)_실거래가_매핑.xlsx 를 mysql의 테이블 2개(거래된 토지, 거래 상세)에 저장 예정.    

* pnu값이 있는 row들만 저장하면 된다.

* individual_land_price_gyeonggi_shp_to_db.py 와 비슷한 형식으로 만들면 된다.

* 실거래가 각 row를 2개의 테이블에 각각 저장, 저장할 값들은 아래 각 테이블별 컬럽대로 저장하면 된다.

* 거래된 토지 테이블
    * 실거래가_매핑.xlsx 에 있는 컬럼들중 상세테이블에 있는 컬럼 제외한 나머지와, 여기에 no컬럼은 제외하고 id를 pk로 넣기, pnu는 여기에도 넣기
    * pnu에 index 설정

* 거래상세 테이블
    * id(pk), 거래된 토지_id(index), pnu ,계약년월, 계약일, 계약면적, 거래금액, 지분구분, 거래유형, 중개소재지
        * '거래된 토지_id' 가 참조필드 역할

* 두 테이블 모두 pnu 타입은 VARCHAR(20)

* '거래된 토지 테이블'에 같은 pnu값을 insert하는 상황이 있을수 있음. 이경우엔 상세테이블에만 insert한다.
