# 실거래가 데이터들의 PNU, 번지 찾기

실거래가 데이터에 해당하는 토지를 찾고, 그 토지의 PNU와 번지를 실거래가에 추가한다.

* data\raw\xlsx\20250806_20260805_토지(매매)_실거래가.xlsx 의 각 데이터엔 번지가 마스킹처리 되있고, PNU가 없다.

* 토지 특성정보인 data\basis\AL_D194_41450_20260520.shp 를 통해 실거래가 데이터의 PNU, 번지를 찾는다.
  * 실거래가 데이터의 시군구, 마스킹된 번지, 지목, 용도지역, 계약면적 등에 해당하는 토지를 토지 특성정보에서 찾는다.
    * 실거래가의 지분구분이 지분인경우는 계약면적을 사용할수 없을것이라 생각한다.
    * 실거래가 지분구분이 빈값이여야, 계약면적이 토지 전체의 면적을 의미한다.


* PNU와 번지를 찾은 실거래 데이터들을 따로 data\processed 에 xlsx 파일로 만든다.
  * 실거래 데이터에 PNU와 번지를 추가
  * 전체 개수와, 찾기 실패한 데이터 수 포함
