# 토지 실거래가 데이터에 매핑되는 토지찾기

토지 실거래가의 자료에는 번지의 일부가 마스킹 처리 돼있다. 토지 특성정보를 이용해, 마스킹 처리 돼있는 번지와 pnu를 구하는게 목표.

* 대상데이터들
    * 토지 실거래가(경기하남) : data\raw\20250806_20260805_토지(매매)_실거래가.xlsx
    * 토지 특성정보(경기도) : data\basis\AL_D195_41_20260519.csv

## 토지실거래가의 각 데이터에 매핑되는 토지 특성정보의 데이터를 찾는다.

매핑 기준 : 아래 모든 사항을 만족하는 토지특성정보의 데이터가 1개인경우, 그 데이터가 실거래가 데이터와 매핑된다.

* 실거래가의 시구군 값과, 토지 특성정보의 법정동명 일치
* 실거래가의 번지에서 *의 앞부분 값으로, 토지 특성정보의 지번 부분이 시작
    * 실거래가의 번지가 '산' 으로 시작할 경우는 분리필요, 뒷부분이 실제 번지에 해당
* 실거래가의 번지가 '산' 으로 시작하는 경우, 토지 특성정보의 대장구분명이 '산'인 데이터만 매칭
    * '산' 으로 시작하지 않는 경우는, 대장구분명이 '산'이 아닌 데이터만 매칭
* 실거래가의 번지의 자리수와, 토지 특성정보의 지번의 본번 자리수 일치
* 실거래가의 지목, 용도지역과 토지 특성정보의 지목명, 용도지역명1 일치
* 실거래가의 지분구분에 값이 없을경우
    * (실거래가의 계약면적 + 0.02) > (토지 특성정보의 토지면적) > (실거래가의 계약면적 - 0.02)
* 실거래가의 지분구분 값이 지분일경우
    * (토지 특성정보의 토지면적) > (실거래가의 계약면적)

## 번지, pnu(고유번호) 값을 실거래 데이터에 추가

번지, pnu(고유번호) 값을 실거래 데이터에 추가해서 data\processed 에 xlsx 파일로 만든다.
* 실거래 데이터 전체 개수와, 그중 값 찾기 성공한 데이터 개수를 xlsx파일에 넣는다.
