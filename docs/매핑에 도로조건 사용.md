# 매핑에 도로조건 사용

| 국토부 실거래가 (도로조건) | 토지특성 도로접면 코드 (01~12) | 매칭되는 토지특성 도로접면 명칭 |
| :--- | :--- | :--- |
| **25m이상** | `01`, `02`, `03` | 광대한면, 광대소각, 광대세각 |
| **25m미만** | `04`, `05` | 중로한면, 중로각지 |
| **12m미만** | `06`, `07` | 소로한면, 소로각지 |
| **8m미만** | `08`, `09`, `10`, `11` | 세로한면(가), 세각(가), 세로한면(불), 세각(불) |
| **`-` (또는 공란)** | `12`, `0` | 맹지, 지정되지 않음 |

* 도로조건과 도로접면코드를 매핑
